# Smart Garage Backend - Hệ Thống Quản Lý Gara Ô Tô Thông Minh

Đây là hệ thống backend hỗ trợ quản lý gara sửa chữa xe ô tô, được xây dựng và phát triển bằng framework **Laravel** kết hợp với **Blade Template**.

## 🚀 Tính năng chính
*   **Quản lý Khách hàng:** Lưu trữ và quản lý thông tin khách hàng đến sử dụng dịch vụ.
*   **Tiếp nhận Dịch vụ & Đặt lịch:** Xử lý luồng dữ liệu tiếp nhận xe và điều phối lịch sửa chữa hợp lý.
*   **Quản lý Kho phụ tùng:** Kiểm soát, thêm/sửa/xóa các loại linh kiện, phụ tùng ô tô.

## 🛠 Công nghệ sử dụng
*   **Backend:** PHP, Laravel Framework.
*   **Frontend:** Blade Template, HTML, CSS, JavaScript.
*   **Cơ sở dữ liệu:** MySQL.

## 📐 Kiến trúc & Vai trò
*   Tự nghiên cứu framework Laravel để thiết kế cấu trúc dự án từ con số không.
*   Xây dựng logic xử lý các luồng nghiệp vụ dữ liệu phức tạp của một hệ thống gara thực tế.
